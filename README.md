* 🔮 Sales forecasting using Linear Regression.

### 💳 2. Credit Risk Intelligence Platform

A machine learning application that analyzes loan data, evaluates borrower risk, compares classification models, and supports credit risk assessment.

**Tech Stack:** Python · Pandas · Scikit-learn · XGBoost · SHAP · Streamlit

* 🏦 Analysis of more than 1.3 million loan records.
* 🤖 Logistic Regression, Random Forest, and XGBoost model comparison.
* 📊 Model evaluation using precision, recall, F1-score, and ROC-AUC.
* 🔍 SHAP-based model explainability.
